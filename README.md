# Remontuj24.pl — WordPress

Nowa strona remontuj24.pl: lekki własny motyw i bloki Gutenberga.

- `brand/` — logo (SVG, tekst na krzywych), karta identyfikacji, skrypty: `tools/build_logo.py`, `tools/prepare_images.py`
- `prototyp/` — animowany prototyp HTML strony głównej (wzór dla motywu)

Motyw i wtyczka z blokami powstaną w kolejnym etapie.
