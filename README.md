# Remontuj24.pl — WordPress

Nowa strona remontuj24.pl: lekki własny motyw i bloki Gutenberga, bez kreatorów stron.

- `wp-content/plugins/remontuj24-core/` — wtyczka: 19 bloków sekcji (pola w panelu edytora, podgląd na żywo), ustawienia firmy, Realizacje, formularz kontaktowy, newsletter (MailerLite, Brevo, Mailchimp), baner cookies, SEO, zdjęcia WebP, import treści startowych
- `wp-content/themes/remontuj24/` — motyw: nagłówek, stopka, szablony stron, artykułów, realizacji, archiwów i 404; CSS i JS bez bibliotek, fonty na własnym serwerze
- `docs/WDROZENIE.md` — instalacja na lh.pl krok po kroku
- `tools/build_zips.sh` — paczki ZIP do wgrania w WordPressie
- `tools/harness/` — podgląd motywu bez WordPressa (porównanie z prototypem)
- `prototyp/` — zatwierdzony prototyp HTML wszystkich podstron (wzór dla motywu)
- `brand/` — logo (SVG) i karta identyfikacji
